Порядок работы

  1. Проверьте названия выработок и плечи блоков на странице «Общий расчёт» (правит администратор) и параметры на странице «Справочник». Допущения помечены: их нужно подтвердить на шахте.
  2. На странице «Электровозы» выберите горизонт (смена или сутки) и нажмите «Рассчитать».
  3. Смотрите результат: «Анимация» показывает движение составов, «Показатели» даёт таблицы, «Графики» даёт выпуск, очереди и диаграмму Ганта.
  4. «Общий расчёт» даёт производительность каждого блока (гор. −480, АТУ, гор. −402); «ПДМ и самосвалы» считает цепочку −402 + АТУ по шагам. Обе страницы пересчитываются сами, кнопки не нужны.
  5. Страница «Схема» показывает маршрут и оценку пропускной способности звеньев без имитации: по ней видно, какое звено ограничивает выпуск.
  6. После изменения справочника выполните расчёт заново: на страницах результата появляется предупреждение, что результат устарел.

Роли

Пользователь (без пароля): расчёт, анимация, показатели, графики, схема, просмотр справочника и справки.

Администратор (пароль): правка и сохранение справочника, импорт данных (версия 0.2), смена пароля, сброс значений. Подробнее о защите: страница «Администрирование».

Два способа запуска

С сервером (run.bat, нужен Python): данные лежат в папке data, страница доступна только с этого компьютера (адрес 127.0.0.1). Пароль администратора проверяет сервер.

В браузере (файл index.html из папки web или опубликованная копия): Python не нужен, расчёт выполняется в самой странице тем же ядром. Справочник, пароль и последний расчёт хранятся в браузере для этого адреса страницы. Очистка данных сайта их удалит, другой браузер начнёт с нуля; копию справочника можно сделать текстом на странице «Администрирование». Пароль в этом режиме защищает только интерфейс: данные в браузере может прочитать и изменить человек с инструментами разработчика, поэтому для общего компьютера выбирайте версию с сервером.

Оба способа дают одинаковые результаты: ядро на JavaScript сверено с ядром на Python на 62 наборах параметров по всем полям результата.

Формулы модели

Модель дискретно-событийная: время в секундах, события в очереди по времени. Каждая формула ниже соответствует коду ядра; значения по умолчанию даны для справочника версии 0.1.

1. Окно работы электровозов

Tэф = (Tсм − tТО,нач − tТО,кон) · КТГ = (36 720 − 1 800 − 1 800) · 0,8 = 26 496 с = 7,36 ч

КТГ — доля времени технической готовности (шахта: 0,8). Ежесменное ТО 2 × 30 мин входит в смену 10,2 ч (подтверждено шахтой). Окно начинается после ТО: [tТО,нач, tТО,нач + Tэф]. Новый цикл начинается только внутри окна, у конца окна очередь у постов снимается. В детерминированном режиме отказы заменены этим усреднённым окном и вторично не учитываются.

2. Скорость и время прохода

v = kv · vпасп / 3,6 = 0,7 · 20 / 3,6 = 3,889 м/с (14 км/ч)
t = L/v + v/(2a) + v/(2b)

Фактических скоростей шахта не дала, поэтому принята доля kv от паспортной скорости Ferrit LF120 (20 км/ч). Время получено из трапецеидального профиля: t = v/a + v/b + (L − v²/2a − v²/2b)/v, откуда остаётся L/v плюс потери на трогание v/(2a) и торможение v/(2b). По умолчанию потери составляют 13,3 + 3,9 = 17,2 с на каждую остановку и последующее трогание.

3. Пути разгона и торможения, короткое ребро

sa = v² / (2a) = 51,8 м; sb = v² / (2b) = 15,1 м
если L < sa + sb: vпик = √(2·L·a·b / (a + b))

На коротком ребре скорость v не достигается, состав разгоняется до vпик и сразу тормозит. Положение головы состава для анимации берётся из этого же профиля, поэтому на экране состав разгоняется и тормозит, а не едет с постоянной скоростью.

4. Ускорение при трогании

a = (Fк − M·g·(w0 + i)/1000) / (1,1·M)

Fк — сила тяги (Ferrit: 55 кН), M — масса поезда (190 т), w0 + i — удельное сопротивление движению и уклон (13 ‰, верхняя граница), коэффициент 1,1 учитывает инерцию вращающихся масс. В справочнике принято a = 0,146 м/с² по расчёту из документа formulas_and_defaults.md (раздел 4). Замедление b = 0,5 м/с² принято по допущению до получения нормативов (вопрос A11).

5. Длина состава и разминовка

Lп = Lлок + n · Lв = 7 + 9 · 6 = 61 м
kр = ⌊ Lразм / (Lп + Lзап) ⌋ = ⌊150 / 71⌋ = 2

Состав должен целиком поместиться на разминовке и иметь запас на остановку. Длины приняты по допущению (вопрос A11), поэтому ёмкость разминовки при другой длине вагона может измениться.

6. Блок-участки и разъезды

tзан = (Lб + Lп) / v

Квершлаги однопутные с двусторонним движением (подтверждено шахтой): состав, первым вошедший в блок-участок, удерживает его до выхода хвоста, встречный ждёт на ближайшей разминовке. При конфликте груженый имеет приоритет перед порожним, затем очередь по времени подхода. С версии 0.14.0 однопутным общим участком для гружёных и порожних составов считается только грузовой квершлаг №1 (С-9 → С-6/С-7, около 756 м): остальные блок-участки у гружёного и порожнего пути раздельные, потому что составы идут по разным выработкам. Если события кончились, а составы всё ещё ждут, фиксируется взаимная блокировка.

7. Погрузка состава

tпогр.сост = tпост + n · (tподача + tПДМ) = 120 + 9 · (60 + 88,2) = 1 453,8 с = 24,2 мин

Постановка под погрузку 2 мин, подача каждого вагона локомотивом 1 мин, цикл ПДМ ST1030 на один вагон 1,47 мин при плече 15 м. Один вагон загружается одним ковшом (10 т), состав из 9 вагонов даёт 90 т. ПДМ ST1030 №2 один на оба поста, поэтому два состава на постах делят один ПДМ и ждут его по очереди.

8. Цикл электровоза без ожиданий (проверка T1)

tц = tпогр.сост + tразгр + 2L/v + 2·(v/(2a) + v/(2b))

При L = 2,4 км получается 2 812 с = 46,9 мин (для 2,2 и 2,6 км: 45,2 и 48,6 мин). Имитация без конфликтов должна давать тот же цикл: это один из тестов ядра. Разгрузка на КДРВ №2: один состав за раз, 90 с.

Блоки и расчёт ПДМ и самосвалов (версия 0.2)

Блок состоит из участков (выработок) с плечами Lj. Время хода по участку tj = Lj · 3,6 / vj, где v в км/ч, t в секундах. Масса руды в ковше q = Vк · kн · γр, γр = γм / kр. Цикл ПДМ tцп = ход по плечу туда и обратно + черпание + манёвры + подъём, разгрузка и опускание ковша. Число ковшей в самосвал nк = ⌊G(1 + δ)/q⌋, фактический груз Gф = nк · q. Цикл самосвала tц = tпос + ⌈nк/nПДМ⌉ · tцп + tг + tразгр + tп.

Звенья цепочки: погрузка Q = nПДМ · 3600 · q / tцп; парк Q = nсм · Gф · 3600 / tц; однополосный участок Q = Gф · 3600 / (tг + tп + 2 · tзап). Производительность цепочки равна наименьшему из звеньев, выпуск за смену Q · Tэф / 3600, Tэф = (Tсм − tТО,н − tТО,к) · КТГСГШО. Нужное число самосвалов ⌈план / (Gф · Tэф / tц)⌉.

Схема машин (с 05.11.2026): самосвал MT436 идёт с −402 по АТУ до кармана С-1, разгружается и возвращается; ПДМ ST1030 №1 подвозит руду и породу из С-1 в карманы С-14, С-15, С-16; ПДМ ST1030 №2 грузит вагоны из карманов (страница «Электровозы»). Подвоз считается звеном цепочки: q = min(Vк · kн · γр ; 10 т), tцп = L · 3,6 / vг + L · 3,6 / vп + tчер + tман + tпод, Q = 3600 · q / tцп; С-16 принимает руду, С-14 и С-15 — породу (доли нормируются по виду груза). Породная смена: каждые четвёртые сутки 08:00–17:00 руда не выдаётся, цепочка считается с плотностью породы γр = γм/kр, руды в среднем за цикл 4 суток 1 − 1/8. Занятость с породой проходки = (Qруда/qр + Qпор/qп) · tцп / Tэф.

Ограничения: однополосный проезд даёт нижнюю оценку (на АТУ разъездов нет — подтверждено; на −402 неизвестны, вопросы F3, F7); очереди и случайные простои не моделируются. Блок −480 считается по схеме электровозов (страница «Схема»), его имитация на странице «Электровозы». Длина пути электровозов равна сумме плеч блока −480.

Проходка и циклограмма забоя (версия 0.5: по фактической циклограмме, класс проходки 5)

Цикл по файлу «Циклограмма проходческих работ, класс 5, Накл. съезд»: две смены по 12 ч (19:00–07:00 и 07:00–19:00), в каждой смене спуск, приведение рабочего места в безопасное состояние, производственные операции и вывоз смены. Заходка делается за две смены: первая смена — откатка и отгрузка горной массы, первичный слой бетона, рама PANTEX, основной слой; вторая — второй приём основного слоя, анкеры, бурение забоя, вспомогательные работы, заряжание, взрыв во время вывоза людей и проветривание. Откатку ведёт ПДМ №4 (подрядчик), погрузку в вагоны — ST1030 №2, параллельно.

Паспорт проходки. Сечение S, длина заходки l, шпур lшп, η, вид крепления (торкрет-бетон, арочное крепление, анкерное; дополнительно сетка и тросовая крепь) подставляются из выбранного класса или справочника; в колонке «Принято» можно ввести своё значение, оно сильнее автоматического. Количества операций (шпуры, ковши, вагоны, миксеры, рамы, анкеры) тоже считаются по формулам и правятся вручную.

l = η · lшп; V = S · l · kпер; M = V · γ; QВВ = q · V; Nшп = ⌈QВВ / (kз · lшп · p)⌉; Nзар = Nшп · kзар
A = (P − b) · l, P = kP·√S; Vторк,i = A · δi · (1 + kотск); nмик,i = ⌈Vторк,i / Vмик⌉; Nанк = ⌈A / (a · b)⌉; nрам = ⌈l / sрам⌉; Nтр = ⌈nкол · l / sкол · доля⌉
nков = ⌈M / qков⌉, qков = min(Vк · kн · γ/kр; 10 т); nваг = ⌈M / mВГ⌉, mВГ = VВГ · kВГ · γ/kр

Нормы времени (минуты) по файлу: t = tпост + n · tед · k.

откатка: t = nков · (L / v) · 60 · 2 · kман (файл: 30 · (0,35/7) · 60 · 2 · 1,2 = 216 мин); отгрузка: t = nваг · 3,5 (20 · 3,5 = 70 мин)
торкрет: t = nмик · 38 · k + tподг (слой 1: 1 · 38 · 1,2 + 20 = 65,6 мин; слой 2: n · 38 + 20 + 20 + 20, 2 миксера — 136 мин); рама: t = n · 30 · 1,25 (37,5 мин)
анкеры: бурение t = n · 2,5 + 20, установка t = n · 1,5 · 1,2 (12 шт.: 50 и 21,6 мин); бурение забоя t = Nшп · 2 + tподг (65 · 2 = 130 мин); заряжание t = Nзар · 1 (55 мин); проветривание 30 мин
смена: Σ tоп + tвсп + tвывоз = Tсм = 720 мин; вспомогательные работы tвсп = Tсм − tспуск − tбез − Σ tоп − tвывоз (остаток смены)

Автоматический режим: операции идут в технологическом порядке, смена заполняется до ёмкости Tсм − tспуск − tбез − tвывоз; что не вместилось — переходит в следующую смену. Число смен в цикле m получается само, Tц = m · Tсм. Анкеры ставятся после пробуренных, заряжаются только пробуренные шпуры. Ручной режим: по каждой смене вводятся количества и минуты (пустая минута берёт норму), есть кнопки «Заполнить из автоматического расчёта» и «Подставить циклограмму из файла»; перегрузка смены и нарушение интервалов выдают предупреждения.

tстарт торк.2 ≥ tконец торк.1 + tсхв; tконец торк.2 + tвыд ≤ tвзрыва; проходка за сутки v = l · 1440 / (m · Tсм / 60 · 60) = l · 24 · 60 / Tц м/сут
M = nз-забоев · S · l · kпер · γ; Qпр = (Tэф / Tц) · M; mВГ = V · kн · γ / kр; Nп = Qпр · доля / (mВГ · nВГ)
остаток на руду = (Nор − Nп) · mс; загрузка откатки = (Qпл/mс + Nп) / Nор
плечо ПДМ −402: Lпдм = Lвыр / 2; плечо откатки: Lотк = Σ Li по кратчайшему пути графа (Дейкстра); −480: Lотк = kизв · √((xз−xп)² + (yз−yп)²)
рейс самосвала с породой: tр = tпос + Lотк/vг + tразгр + Lотк/vп; nр = Qпр / (G·(1+δ)); самосвало-часы = nр · tр / 3600

Блок «Горизонт и плечи откатки» на странице «Проходка»: наименование горизонта и участки откатки вводятся вручную (таблица, добавление и удаление участков) либо считаются по чертежам проектов. Для гор. −402 используется граф плана от 25.09.2026 (длины по пикетажу ΔПК·20 м и оценке контуров; можно продолжить по АТУ до С-1), для гор. −480 — хорда между координатами узлов, умноженная на kизв (связного рельсового графа в чертеже нет, A10). Плечо ПДМ входит в цикл уборки, плечи откатки — в рейсы самосвалов и баланс откатки. Данные чертежей лежат в файле js/drawings.js.

Горная масса проходки грузится ST1030 в ВГ-5,8 (породные карманы С-14 и С-15), идёт составами на КДРВ №2 и занимает электровозы, посты, ПДМ и КДРВ наравне с рудными составами. Баланс показан на страницах «Проходка», «Общий расчёт» и «Электровозы»; на «ПДМ и самосвалы» порода −402 добавлена к потоку по АТУ. Имитация электровозов считает только рудные составы.

Допущения: один забой, машины заняты только им; нормы времени взяты из файла и калибровка количеств класса 5 (толщины слоёв, шаг анкеров, расход ВВ, ковш) подобрана под него, а не взята из паспорта (вопросы H15–H19).

Проходка на гор. −480 с локомотивной откаткой (версия 0.6)

Вкладка «Проходка −480 (электровозы)»: бурение Epiroc Boomer T1D, уборка ПДМ 1 м³ в вагоны ВГ-5,8, откатка электровозом, крепление рамами СВП-27 и дополнительные виды крепления, капитальные коммуникации. Смены, окна ВР и раскладка по сменам те же, что на странице «Проходка» (параметры d_cg_*); два режима — автоматический и ручной (количества и минуты по сменам).

Условия и шаг рам. Четыре набора условий: 1 — шаг 1 м, 2 — 0,75 м, 3 — 0,5 м (проколы, подкрепка СВП-22, затяжка), 4 — самые негативные, шаг 0,25 м (проколы, СВП-22, тросы). Любое значение паспорта и вид крепления правятся вручную. Длина заходки кратна шагу: l = nрам · s, при этом l ≤ lшп · η.

l = nрам · s; V = S · l · kпер; M = V · γ; QВВ = q · V; Nшп = ⌈QВВ / (kз · lшп · p)⌉; lшп = min(lшп,max; l / η)
P = kP · √S; A = (P − b) · l (контур без почвы); масса рамы mСВП = gпр · P · kзам (СВП-27: 27 кг/м, СВП-22: 22 кг/м, периметр 0,85 от СВП-27)
опережающее крепление: Nпр = ⌈(kсв · P / sпр) · l / (Lпр − Lпер)⌉, Lпр = 4 м; t = tподг + Nпр · tпр
затяжка и забутовка: Aз = kз · A; Vлес = Aз · (δз + kб · δб); t = Aз · tм²; подкрепка: N22 = ⌈k22 · nрам⌉
бетон по полному сечению без почвы: Vб = (P − b) · l · δ · kпот; nмик = ⌈Vб / Vмик⌉; t = tопал + nмик · tмик; взрыв не раньше tвыд после бетона
коммуникации (рельсовый путь, вода, сжатый воздух): t = l · tм для каждого вида; путь прокладывается до следующей уборки

Уборка и откатка. ПДМ 1 м³ грузит вагоны, электровоз возит составы по плечу откатки от забоя до разгрузки; пока состав в пути, ПДМ ждёт порожний (при двух составах ожидание сокращается).

qков = Vк · kн · γ/kр; nков = ⌈M / qков⌉; tков = 2 · (Lпдм/vпдм) · 60 · kман + tчер; nваг = ⌈M / mВГ⌉
tрейс = 2 · (Lотк/vэл) · 60 + tман + tразгр; tнаполн = (nВГ · mВГ / qков) · tков; tожид = max(0; tрейс − tнаполн) при двух составах, иначе tрейс; tубор = nков · tков + (nсост − 1) · tожид
бурение: t = tподг + Nшп · (lшп / vбур + tшп); заряжание t = Nзар · tз; заходок за сутки = 2 · (число заходок за смену), проходка v = l · заходок/сут

Все нормы времени, массы профилей, толщины и скорости лежат в справочнике (параметры r_*) и заданы допущениями до получения паспорта крепления и БВР; список вопросов — H21–H29. Порода идёт в ВГ-5,8 составами на разгрузку по плечу откатки и занимает электровозы наравне с рудными составами. Имитация электровозов считает только рудные составы.

Свёрнутые формулы и расчёты

Офлайн и значок на экране «Домой»

Браузерная сборка работает без сети и ставится как приложение. Все данные (справочник, правки узлов трассы, суточные планы, последний расчёт) лежат только в памяти устройства и никуда не передаются.

  1. Один раз откройте папку сборки по адресу https или http://localhost (с файла установка недоступна).
  2. Android, Chrome: кнопка «Установить на экран Домой» на главной или меню браузера → «Установить приложение». iPhone и iPad, Safari: «Поделиться» → «На экран Домой».
  3. После первой загрузки страницы открываются без сети. Новая версия подтягивается при следующем запуске с сетью.
  4. Очистка данных сайта в браузере стирает записи: на главной нажимайте «Сохранить копию данных», «Восстановить из копии» возвращает файл.

Настройки и обновления

«Настройки»: сведения о версии и кнопка «Выгрузить приложение (ZIP)», которая сохраняет на устройство всё приложение одним архивом. «Обновления»: кнопка «Проверить обновление» сравнивает установленную версию с файлом version.json на сайте-источнике. Вкладка «Источник» задаёт адрес сайта вручную или оставляет автоматический (адрес, с которого открыта страница).

  1. Новую сборку выкладывают на хостинг поверх старой, вместе с version.json.
  2. В приложении нажимают «Проверить обновление»: в окне будет либо «Доступно обновление», либо «Обновлений нет».
  3. Если источник совпадает с адресом приложения, «Установить обновление» заменяет страницы на месте, данные остаются. Если адрес другой, данные не переносятся: перед переходом сделайте копию в «Настройках».

Справочник: суточное планирование (версия 0.10)

Вкладка «Суточное планирование» на странице «Справочник». В строке задаются вид груза (руда или порода), плановый объём за сутки, начало маршрута (точка отгрузки) и конец маршрута (точка разгрузки). Плечо откатки считается автоматически и показывается по участкам; при необходимости его можно ввести вручную. Данные хранятся в этом браузере.

L = Σ Lj; т·км = Q · L / 1000; Lср = Σ(Qi · Li) / ΣQi

Гор. −402: путь по графу плана (по пикетажу), АТУ до С-1 из справочника блоков, ПДМ С-1 → карман, электровозы по трассе −480. Участки −480 без графа считаются как хорда × kизв (вопрос A10).

Меню «Расчёты», схема гор. −480 и узлы (версия 0.9)

Шесть расчётных вкладок (ПДМ и самосвалы, Проходка, Проходка −480, Добыча, Скреперная добыча, Электровозы) собраны на отдельном экране «Расчёты»: пункт меню открывает список, внутри вкладки есть ссылка «← Расчёты».

На странице «Анимация» состав показан на схеме трассы по чертежу гор. −480: узлы подписаны наименованиями плана, гружёная трасса идёт от сопряжения С-20 (прямая погрузка с АТУ) к КДРВ №2, порожняя возвращается другим путём (с 0.13.0: через С-1 (46), С-2, С-8, С-7, С-9, С-10, С-50, С-47, С-48, С-68, С-70, С-30, С-31). Кнопка «Узлы» открывает страницу со всеми наименованиями узлов, участков трассы, плеч из справочника и выработок чертежа.

Узлы трассировки правятся на странице «Узлы»: наименование и координаты узла, порядок узлов (↑ ↓), убрать узел с трассы или добавить любой узел, создать свой узел по координатам X, Y. Поправки хранятся в этом браузере; кнопка «Сбросить поправки» возвращает трассу по плану.

f = x / Lпуть; s = f · ΣLхорд; точка трассы — на ломаной по накопленной длине; Lучастка,мод = Lхорды / ΣLхорд · Lпуть

Связного рельсового графа в DXF нет (вопрос A10), поэтому узлы соединены прямыми отрезками в порядке по плану. Схема показывает порядок узлов, а не точную геометрию выработок. Положение состава на схеме пропорционально модельной координате.

Добыча: подэтажное принудительное обрушение с торцевым выпуском (версия 0.8)

Руда отбивается веерами скважин из буро-доставочных штреков (БДШ), выпуск ведётся с торца штрека ПДМ. Параметры веера подставляются из справочника (m_*, паспорт бурения и взрывания вееров) и правятся вручную; ЛНС считается тремя способами и принимается как среднее либо вводится вручную; после этого проверяются риски.

Hв = h · kв; β = arctg(b · kпер / (2 · Hв)); Li = Hв / cos αi; n = ⌈2β · Lмакс / a⌉ + 1, a = m · W
Aв = Hв² · tg β; V = Aв · W; M = V · γр · kр; p = π d² Δ / 4; qф = p · Σ(Li − lзаб) / V
ЛНС: A) W при qф(W) = q = q0 + kq · f; B) W = 53 · kв · d · √(Δ / γм); C) W = 30 · d; Wавто = среднее трёх
Проверки: W в диапазоне способов; qф к q (±15 %, ±30 %); a / W (0,8…1,3); δ = kоткл · Lмакс к W (0,15; 0,25); rмин = kзар d / Δα у устья; Lмакс к ходу станка; kпер (0,95…1,25); W / d (20…40)
Nбур = nст Tэф / tбур; Nзар = nмаш Tэф / tзар; Nвып = Tэф / tвып; Qсм = min(N) · M · η

Критерии проверки и способ B (формула типа Покровского) нужно подтвердить по нормативу предприятия. Паспорт вееров, станок, диаметр, ВВ и высота подэтажа заданы допущениями, вопросы J1…J7.

Скреперная добыча на гор. −480 (версия 0.7)

Руда доставляется скреперами и грузится в вагоны с откаточных ортов №28, №27 и №26; с них отгружается недостающее до плана смены количество руды. Трассы ортов взяты из плана гор. −480 (оси по выноскам, концы по примыканию к юго-западному и юго-восточному штрекам, зона погрузки по сетке штреков ШС-5…ШС-13): длина около 480, 455 и 450 м.

Qнд = max(0; Qпл − Q−402), Q−402 = min(Qпл,−402; Qцепочки)
qков = Vс · kн · γ; tц = L / vгр + L / vпор + tпер; Qч = 3600 · qков · kисп / tц
Ci = ni · Qч · Tэф / 3600, Tэф = (Tсм − tТО,н − tТО,к) · КТГ; u = min(1; Qнд / ΣCi), Qi = u · Ci
Ni = Qi / mсост; Li = kизв · хорда(люк → КДРВ №2); tц,эв,i = tц,схемы + 2 · (tход,i − tход,схемы) + (tпогр,i − tпогр,схемы)
загрузка откатки = (Q−402 + ΣQi) / (Nmax · mсост); руда за сутки = 2 · Qсмены · 7/8 (в породную смену руда не выдаётся)

Параметры скреперов (ковш, скорость каната, длина скреперования, число установок, КТГ) заданы допущениями в справочнике (s_*), вопросы I1–I6. Расчёт аналитический: очереди и объём бункеров под люками не моделируются.

Пропускная способность звеньев

Оценка без имитации (страница «Схема»). Для каждого звена считается, сколько составов в час оно может пропустить:

электровозы: nЭВ · 3600 / tц; посты: nпост · 3600 / tпогр.сост
ПДМ: nПДМ · 3600 / (n · tПДМ); КДРВ: 3600 / tразгр; блок-участок: 3600 / (2 · tзан)
Nор = min(звенья) · Tэф / 3600; потребность плана: Nпл = Qпл / (n · mв)

Узкое место — звено с наименьшей пропускной способностью. Блок-участок занят два раза за цикл (гружёный и порожний проход), отсюда множитель 2. ПДМ делится на все посты сразу, поэтому его предел часто ниже предела постов. Nор — ориентир, а не строгая граница: имитация даёт меньше из-за пуска первого цикла и ожиданий (при параметрах по умолчанию 32 состава против 33,4), а больше — только на составы, которые стоят на постах в конце окна и дозагружаются после него (до числа постов).

Две системы разработки: SLC и GSC

Шахта работает по двум системам, и обе используют одни и те же пути и электровозы Ferrit. SLC грузит составы напрямую с АТУ на сопряжении С-20: под погрузкой стоит один состав, вагонетку заполняет один ковш ПДМ. GSC грузит составы скреперными лебёдками с откаточных ортов №26, №27 и №28: у каждого орта свой пост, три поста работают независимо, ПДМ не нужна.

план шахты Qпл = QSLC + QGSC; факт Q = QSLC + QGSC
SLC: tпогр.сост = tпост + n · (tподача + nков · tПДМ)
GSC: tпогр.сост = tпос + n · tв, tпос = 5 мин (подача и смена состава у люка), tв = 2 мин на вагон
nSLC = nЭВ − nGSC − nрез − nрем − nпор
максимум шахты за смену = Qмакс,SLC + Qмакс,GSC, где для каждой системы Qмакс = min(звенья) · Tэф / 3600 · n · mв

Роль каждого электровоза выбирается вручную на странице «Электровозы»: SLC, GSC, резерв, ремонт или уборка породы. Электровозы в резерве, ремонте и на породе рудную откатку не ведут и в средней загрузке не учитываются. Общий участок обеих систем это грузовой квершлаг №1 (756 м): там один блок на оба направления и обе системы, при освобождении его получает гружёный состав. Составы GSC разгружаются на КДРВ №1, в справочнике можно выбрать общий КДРВ №2. Длины путей GSC (гружёный 3242 м, порожний 4175 м) усреднены по трём ортам, длины по каждому орту приведены на странице «Узлы» в таблицах 2д и далее.

Показатели

выполнение плана = выгружено / (Qпл · число смен)
производительность в окне = выгружено / (ΣTокон / 3600), т/ч
загрузка электровоза = (tход + tпогр + tразгр) / ΣTокон
загрузка ресурса = время занятости внутри окон / ΣTокон (ПДМ дополнительно делится на nПДМ)
баланс массы = погружено − выгружено − в пути = 0

Ожидания считаются по причинам: пост, ПДМ, КДРВ, блок-участок, выработка (встречный состав), стоянка на разминовке. Загрузка ресурсов считается только внутри окон работы электровозов, поэтому технологические перерывы не занижают её. Баланс массы проверяет, что в расчёте груз не появляется и не пропадает.

Состояния электровоза

На диаграмме Ганта каждому состоянию соответствует свой цвет. В анимации оранжевый состав гружёный, синий порожний, красная рамка означает ожидание.

Границы версии

  • Груз в камерах не ограничен, подвоз с С-1 считается аналитически (без очередей и объёмов карманов). Выпуск выше 100 % плана — результат этого допущения, а не оценка факта.
  • Путевая схема условная: равные блок-участки и одинаковые разминовки. Данные для реальной схемы: вопрос A10.
  • Длины подвижного состава и тормозной путь взяты по допущению (A11). Фактические циклы для калибровки: вопрос B8.
  • Диспетчер жадный и не предотвращает тупики: при трёх и более постах и двух и более ПДМ составы могут заблокировать друг друга на однопутной цепочке (расчёт покажет красное предупреждение). При параметрах по умолчанию блокировок нет.
  • Режим только детерминированный. Стохастика с отказами (MTBF, MTTR), электровозы К-14, бетон и сценарии «что, если» — следующие версии.
  • Потери на разгон и торможение добавляются ко времени, а не моделируются по всему профилю.
