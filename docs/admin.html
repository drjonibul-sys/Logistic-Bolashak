Администрирование

Пароль администратора, расположение данных на диске и защита входа. Приложение работает только на этом компьютере.

Раздел доступен администратору.

Сменить пароль

Пароль не короче 12 символов. После смены другие сеансы администратора закрываются.

Справочник параметров

Вернуть все параметры к значениям по умолчанию (изменения администратора будут удалены).

Перенос справочника

Значения справочника хранятся в этом браузере. Чтобы сохранить копию или перенести их на другой компьютер, нажмите «Показать текущие значения» и скопируйте текст. Чтобы загрузить, вставьте текст и нажмите «Загрузить».

Состояние приложения

Резервная копия: закройте программу и скопируйте папку данных. Забытый пароль: удалите файл admin.json в папке данных и задайте пароль заново.
