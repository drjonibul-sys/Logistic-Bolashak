## 2. Длины (рейс самосвала до кармана С-1 — 711 м, см. раздел 6; L = Σ |P_i − P_{i−1}| по меткам пикетов; проверка L ≈ 20·ΔПК)
- АТУ ПК-0 → ПК-33: L = 652,1 м (20·33 = 660 м, расхождение 1,2 %).
- ПК-33 → заезд на п/э −402: 23,5 м. Всего ПК-0 → заезд: **675,6 м**.
- Съезд С-55 → ПК-0: ≈ 15 м (оценка по контуру, сопряжение косое).
- Съезд С-20 → АТУ (ПК-4): ≈ 29 м (оценка по контуру).
- Расстояние между сопряжениями по штреку: С-55 → С-20 ≈ 81 м.
- **От С-55 до заезда:** 15 + 675,6 ≈ **691 м**.
- **От С-20 до заезда:** 29 + (675,6 − 80,9) ≈ **624 м** (ПК-4 стоит на 80,9 м от ПК-0).
- В блоке «АТУ» приложения сейчас допущение 520 м (оценка по уклону 14 %). План даёт на 20–33 % больше.

## 4. Время рейса по плечу (скорости 8 км/ч гружёный, 12 км/ч порожний — допущение блока АТУ)
t_г = L / v_г; t_п = L / v_п.
- L = 624 м: t_г = 624 / 2,222 = 281 с; t_п = 624 / 3,333 = 187 с; сумма 468 с (7,8 мин).
- L = 691 м: t_г = 311 с; t_п = 207 с; сумма 518 с (8,6 мин).
- Пропускная способность однополосного проезда: n = 3600 / (t_г + t_п + 2·t_зап) = 3600 / (468 + 20) = 7,4 рейса/ч для L = 624 м (t_зап = 10 с).
