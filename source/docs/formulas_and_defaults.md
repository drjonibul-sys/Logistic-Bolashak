# Расчётные формулы и допущения (гор. −480, шахта «Болашак»)

Обозначения: F_ч — сила тяги по характеристике, кН; F_сц — тяга по сцеплению, кН; ψ — коэффициент сцепления; P_сц — сцепная масса локомотива, т; g = 9,81 м/с²; w₀ — основное удельное сопротивление, ‰; i — уклон, ‰ (подъём «+», спуск «−»); m_т — масса порожнего вагона, т; m_гр — масса груза в вагоне, т; n — число вагонов; a — ускорение, м/с²; 1,1 — коэффициент инерции вращающихся масс.

Все числа ниже пересчитаны кодом и соответствуют значениям по умолчанию из requirements_summary.md. Допущения помечены «подтвердить».

## 1. Груз в вагоне

- Масса груза: `m_гр = V · k_н · γ_разр`.
- ВДР-5,3 (руда): `5,3 · 0,85 · (2,3…2,5) = 10,4…11,3 т`.
- Загрузка по грузоподъёмности: `K_гп = m_гр / Q_ном = 10,4…11,3 / 15 = 0,69…0,75`. Вагон ограничен объёмом, а не грузоподъёмностью.
- Плотность, при которой вагон выходит на 15 т: `γ = 15/(5,3·0,85) = 3,33 т/м³`. Это плотность руды в массиве, поэтому 15 т используется как контроль перегруза.
- Состав из 9 вагонов ВДР: `Q = 9 · m_гр ≈ 93…101 т` руды.
- Породная вагонетка 5,8 м³: `m_гр = 5,8 · 0,85 · 1,7 = 8,4 т` (γ породы 1,7 т/м³, подтвердить).

## 2. Сила тяги

- Реализуемая сила тяги: `F_к = min(F_ч ; F_сц)`, `F_сц = ψ · P_сц · g`.
- Ferrit LF120, нижняя граница допуска: `F_ч = 55 · 0,95 = 52,25 кН`.
- Потребная сцепная масса: `P_сц ≥ F_к/(ψ·g)`. При ψ = 0,24…0,17 для 52,25 кН нужно 22…31 т, для 55 кН 23…33 т.
- К-14: `ψ = 25/(14·9,81) = 0,18` (часовой режим), при расчёте принимается ψ = 0,17, `F_сц = 0,17·14·9,81 = 23,4 кН`.

## 3. Предельная масса поезда

- По тяге, полная масса с локомотивом: `M_max = 1000·F_к / (g·(w₀ + i))`, т.
- Ferrit LF120 при w₀ = 8 ‰: 55 кН, i = 3 ‰ → 510 т; 55 кН, i = 5 ‰ → 431 т; 52,25 кН, i = 5 ‰ → 410 т.
- Масса груженого состава Ferrit: `M = n·(m_т + m_гр) + P_лок = 9·(6 + 10,4…11,3) + 35 ≈ 182…190 т` (m_т = 6 т и P_лок = 35 т подтвердить). Запас по тяге 2,2–2,7 раза, тяга не ограничивает 9–10 вагонов, ограничивают сцепление при трогании и торможение.
- Масса вагонов в составе по тяге: `Q_max = M_max − P_лок`.

## 4. Ускорение при трогании

- `a = (F_к − M·g·(w₀ + i)/1000) / (1,1·M)`.
- Ferrit, M = 190 т, w₀ + i = 13 ‰: при 55 кН `a = 0,146 м/с²`, при 52,25 кН `a = 0,133 м/с²`.

## 5. Число вагонов у К-14

- `n = ⌊ ( F_к / ( g·(w₀+i)/1000 + 1,1·a ) − P_лок ) / (m_т + m_гр) ⌋`.
- Допущения: ψ = 0,17, F_к = 23,35 кН, a_min = 0,05 м/с², w₀ = 8 ‰, P_лок = 14 т (принята равной сцепной массе, подтвердить), m_т = 6 т, m_гр = 8,4 т.
- Результат: i = 0 → n = 11; i = 5 ‰ → n = 7. Согласуется с данными шахты: максимум 10 вагонов, в среднем в работе 8.

## 6. Разминовки и интервалы

- Условие размещения состава на разминовке: `L_разм ≥ L_сост + L_зап`.
- Минимальный интервал между составами на блок-участке: `I_мин = (L_торм + L_сост + L_зап)/v`.
- Тормозной путь и допустимые скорости по участкам принимаются по правилам безопасности и локальной инструкции шахты (подтвердить).

## 7. Бетон

- Проверка рейса миксера: `t_рейса ≤ t_жив`. Срок жизнеспособности смеси t_жив задаётся в справочнике.

## 8. Калибровка по фактическим рейсам

- Фактическое сопротивление: `w₀ = (F_к/(M·g) − i/1000 − 1,1·a/g)·1000`, ‰. Если ускорение установившегося движения равно нулю, последний член исчезает.
- Хронометраж рейсов позволит заменить значения по умолчанию (8 ‰ и 10 ‰).

## 10. Справочные циклы СГШО (значения по умолчанию, в приложении правятся вручную)

Обозначения: m_ков — масса груза в ковше, т; V_ков — объём ковша, м³; k_н — коэффициент наполнения; γ — плотность разрыхлённой массы, т/м³; L — плечо в одну сторону, м; v_гр, v_пор — средние скорости гружёного и порожнего хода, км/ч; N — число ковшей на машину; k_и — коэффициент использования времени.

1. **Груз в ковше:** `m_ков = min(G_ном ; V_ков · k_н · γ)`. ST1030 (V = 5,0 м³, k_н = 0,9, γ = 2,4 т/м³): min(10; 10,8) = 10 т. ST14 (V = 6,4 м³, типоразмер ковша подтвердить): min(14; 13,8) = 13,8 т. Порода γ = 1,7 т/м³ у ST1030: 7,65 т.
2. **Время хода:** `t_х = 0,06 · L · (1/v_гр + 1/v_пор)`, мин. Средние скорости по умолчанию: ПДМ 8 / 10 км/ч, самосвал 8 / 12 км/ч (ниже паспортных из-за кривых и разъездов, гружёный идёт вниз по уклону). Каждые 100 м плеча добавляют 1,35 мин у ПДМ и 1,25 мин у самосвала.
3. **Цикл ПДМ:** `t_ц = t_чер + t_разгр + t_ман + t_х`. По умолчанию t_чер = 0,5 мин, t_ман = 0,5 мин (допущения). t_разгр по паспорту (подъём + разгрузка + опускание): ST1030 16,1 с = 0,27 мин, ST14 14,6 с = 0,24 мин. ST14 при плече 30 м (8 / 10 км/ч): `t_ц = 0,5 + 0,24 + 0,5 + 0,41 = 1,65 мин`.
4. **Ковши в самосвал:** `N = ⌊G_ам·(1 + δ) / m_ков⌋`, δ — допустимый перегруз (по умолчанию 5 %, правится вручную, δ = 0 даёт строго «не больше грузоподъёмности»). ST14 (руда): ⌊31,5/13,8⌋ = 2 ковша = 27,6 т (0,92 от 30 т), три ковша дали бы 41,5 т. ST1030 (порода, γ = 1,7): ⌊31,5/7,65⌋ = 4 ковша = 30,6 т (1,02 от 30 т), три ковша дали бы только 22,95 т (0,77).
5. **Рейс самосвала:** `t_р = t_под + N·t_ц + t_разгр + t_ман + t_х`. По умолчанию t_под = 0,7 мин, t_разгр = 14 с = 0,23 мин, t_ман = 0,8 мин; постоянная часть 5,03 мин. Производительность `Q = 60·N·m_ков·k_и / t_р`, k_и = 0,8. При L = 400 / 600 / 800 м: t_р = 10,0 / 12,5 / 15,0 мин, Q = 132 / 106 / 88 т/ч.
6. **Самосвалов на одну ПДМ:** `n = t_р / (N·t_ц + t_под)` = 2,5 / 3,1 / 3,8 при тех же плечах.
7. **Погрузка ВДР из камер С-14 и С-15 (ST1030):** один ковш 10 т это 79 % геометрического объёма вагона при γ = 2,4 (5,3 · 2,4 = 12,7 т); два ковша дали бы 20 т, то есть перегруз по объёму. Принят `N_ков = 1` (правится вручную): 10 т на вагон и 90 т на состав из 9 вагонов, а не 93–101 т по расчёту kн = 0,85. Цикл ПДМ у вагона при плече 15 м: 1,47 мин, подача вагона локомотивом 1,0 мин, итого 2,47 мин на вагон. Погрузка состава из 9 вагонов 22,2 мин плюс постановка 2 мин = 24,2 мин. Пропускная способность поста `10 / 2,47 · 60 = 243 т/ч`.
8. **Перегрузка С-1 → С-14/С-15 (ST1030):** `t_ц = 0,5 + 0,27 + 0,5 + 0,06·L·(1/8 + 1/10)`, плечо L нужно ввести (на 100 м +1,35 мин).

9. **Порода (γ = 1,7 т/м³, подтвердить; для ультраосновных пород вероятно 1,7–2,0):** ковш ST1030 7,65 т. ВГ-5,8 вмещает `5,8·0,85·1,7 = 8,4 т`, один ковш занимает 91 %. ВДР-5,3 в породную смену `5,3·0,85·1,7 = 7,66 т`, то есть один ковш почти точно заполняет вагон. Состав из 9 ВДР породой несёт 68,9 т, из 10 ВГ 76,5 т. Ковшей на вагон по умолчанию 1.
10. **Рейс самосвала с породой (ST1030 грузит 4 ковша):** цикл ST1030 в забое при плече 30 м равен 1,67 мин, постоянная часть рейса 8,43 мин. При плече 400 / 600 / 800 м `t_р` = 13,4 / 15,9 / 18,4 мин, Q = 109 / 92 / 80 т/ч (k_и = 0,8), одна ST1030 обслуживает 1,8 / 2,2 / 2,5 самосвала.
11. **ST1030 №2 (перегрузка из С-1 и погрузка вагонов на −480), вероятное узкое место.** На ковш: `t = t_ц(L) + t_ц(15 м) + t_под`, `Q = 60·m_ков·k_и / t`. Руда (10 т) при плече L = 200 / 400 / 600 м: 6,44 / 9,14 / 11,84 мин на ковш, Q = 75 / 53 / 41 т/ч. Порода (7,65 т): 57 / 40 / 31 т/ч. Два самосвала при плече 600 м вывозят до 212 т/ч руды (без учёта породы), поэтому пропускная способность связки определяется ST1030 №2 и плечом С-1 → С-14 / С-15 / С-16. Оценка предварительная, нужна трассировка и фактические плечи.

Ограничения модели: в рейсах не учтены ожидание и простои на разъездах автотранспортного уклона, ТО и ремонт. Распределение техники по данным шахты: ST1030 №1 только порода на −402, ST1030 №2 перегрузка из С-1 и погрузка вагонов на −480, обе ST14 на руде −402.
