# Журнал изменений приложения «Логистика гор. −480»

Файл ведётся в каждом чате по разработке. Перед правкой приложения его читают целиком, чтобы сохранить логику прежних изменений. Для новых приложений проекта берут из него раздел «Ошибки, которые нельзя повторять».

## Среда
- Использование: iPhone 13 Pro (iOS 26 и новее) и iPad Pro 10,5 (iOS 17), локально, как приложение с экрана «Домой».
- Обновление: через бесплатный хостинг (GitHub Pages, Cloudflare Pages, Netlify). Адрес сайта вводится вручную на вкладке «Источник» либо определяется сам при первой публикации.
- Данные хранятся в localStorage (ключи lg1.* и lg.*). Адрес сайта задаёт хранилище, поэтому смена адреса данные не переносит.

- Параметры реестра (по умолчанию 0, участок выключен, прежние расчёты не меняются): L_atu, L_atu_e, L_atu_g, x_atu_gsc. Участок включается, когда заданы все четыре, есть GSC, один пост SLC и общий участок. Всего 225 параметров. Его пропускная способность 3600 / t_зан,SLC · (1 − N_GSC · t_зан,GSC / T_эф), где t_зан,SLC = 2a + b + (L_уч,п + L_уч,гр + L_п) / v + t_погр.сост, t_зан,GSC = (L_уч + L_п) / v. В звенья GSC добавлена собственная строка. capacity.zone хранит оба времени занятия и долю участка, занятую проездами GSC.
- Результат при умолчаниях за смену: 3060 т (SLC 1440 т, 16 составов, план 1200; GSC 1620 т, 18 составов, план 1680, выполнение 96 %) вместо 3870 т без участка. Максимум по технике: SLC 1415 т (лимит участок), GSC 2097 т, шахта 3512 т. Блокировок нет, баланс 0.

- Тесты: паритет JS и Python расширен 11 наборами с участком; тест Python проверяет, что состав GSC ни разу не получил участок при занятом посте SLC; тесты JS и Python на снижение выпуска, строку схемы и отключение участка при двух постах SLC или без GSC.

## Ошибки, которые нельзя повторять
- Политика CSP сервера запрещает inline-скрипты и inline-стили (default-src 'self'). Все стили в style.css, обработчики в js. Динамически созданные окна оформляют классами.
- Новый скрипт нужно добавить в JS_FILES сборки и в список файлов service worker, иначе офлайн-версия его не получит.
- Эвристика, которая сворачивает таблицы по заголовку th, ловила служебные таблицы: нужна строка заголовков только из th.
- Service worker работает только на https и localhost. С file:// установка недоступна.
- Хранилище в песочнице или приватном режиме может быть недоступно: все чтения и записи оборачивать в try/catch.
- Тест ui_check в режиме browser иногда падает по таймауту на разных шагах. Это известная нестабильность, при подозрении прогонять заново.
- Загрузка в проект через Projects project_write: локальный файл должен лежать внутри рабочей папки.
- Web Share и скачивание на iOS требуют нового нажатия пользователя. Сборку архива и скачивание нельзя разносить по таймеру.
- Проверка обновления не должна читаться из кэша: version.json исключён из кэша service worker, к запросу добавляется временная метка.
- Тексты документов проходят правила Humanizer: без длинных тире, без оборотов «не X, а Y», без жирных подписей в списках.
