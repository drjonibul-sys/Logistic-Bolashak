# Материалы проекта

Здесь лежат документы и исходные данные, на которых построено приложение.

- `change_log.md`, `formulas_and_defaults.md`, `requirements_summary.md`, `simulation_model_concept.md`, `open_questions.md`: рабочие документы проекта.
- `drawings/`: чертежи планов горизонтов −402 и −480 в формате DWG.
- `dxf_horizon402/`: выгрузка и анализ плана −402 (метки, сечения, разломы, черновой граф).
- `dxf_horizon480/`: скрипт разбора плана −480 (`parse_dxf_horizon480.py`) и результат его работы по плану от 05.11.2026 (`plan_2026-11-05/`). Таблицы по более раннему плану (версия от 13.10.2026) остались в проекте Claude «Горный передел и все что связано», папка `logistika-app/dxf_horizon480`.
- `dxf_horizon480_atu/`: трасса АТУ на горизонте −480 (станции, отметки).
- `excel/`: список открытых вопросов и движение электровоза по горизонту −480.
- `quick_calc_artifact/`: страница «Быстрый расчёт гор. −480» (на согласовании).
