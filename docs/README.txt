Логистика гор. -480: версия для запуска в браузере.
Откройте файл index.html двойным щелчком (лучше в Chrome или Edge). Python и сервер не нужны.
Данные (справочник, пароль администратора, последний расчёт) хранятся в браузере для этого файла.

Офлайн-приложение на телефон/планшет (значок на экране «Домой»):
1. Один раз выложите эту папку на любой адрес https (например, внутренний сайт, GitHub Pages) или запустите
   на компьютере: python -m http.server 8080 в этой папке и откройте http://АДРЕС:8080/ с устройства.
   Service worker работает только на https или localhost; с file:// установка недоступна.
2. Откройте адрес один раз при сети: все страницы сохранятся в память устройства.
3. Android/Chrome: меню → «Установить приложение». iPhone/iPad (Safari): «Поделиться» → «На экран Домой».
4. Дальше сеть не нужна; все данные хранятся только на устройстве (на главной есть «Сохранить копию данных»).

Обновление: загрузите новую сборку на тот же адрес поверх старой (version.json должен лежать рядом с index.html).
В приложении: Настройки → Обновления → «Проверить обновление». Адрес источника можно задать вручную: Обновления → «Источник».
Выгрузка всего приложения в ZIP: Настройки → «Выгрузить приложение».
