# Логистика гор. −480, версия 0.1.2 (имитация движения электровозов)

Многостраничное веб-приложение, которое запускается двумя способами. Страницы и ядро расчёта одни и те же.

| Способ | Что нужно | Где хранятся данные | Для чего |
|---|---|---|---|
| **В браузере** (`web/index.html`) | только браузер (Chrome или Edge), Python не нужен | в самом браузере (localStorage) | быстро открыть, показать, посчитать |
| **С сервером** (`run.bat`) | Python 3.9 или новее | папка `data` | общий компьютер, пароль под защитой сервера |

Интерфейс многостраничный: у каждого раздела своя страница и общее меню слева.

## Запуск в браузере (без Python)
1. Распакуйте архив в любую папку.
2. Дважды щёлкните `run_browser.bat` или откройте файл `web/index.html` в Chrome или Edge.
3. Данные (справочник, пароль администратора, последний расчёт) хранятся в браузере для этого файла. Очистка данных сайта их удалит. Копию справочника можно сделать текстом: «Администрирование» → «Перенос справочника».
4. Пароль администратора в этом режиме защищает только интерфейс: человек с инструментами разработчика браузера может прочитать и изменить данные. Если важна защита, используйте версию с сервером.
5. Если браузер запрещает хранилище (режим инкогнито, запрет данных сайтов), страница об этом предупредит: данные сохранятся только до закрытия вкладки.

Папка `web/` собирается из тех же исходников командой `python tools/build_web.py` (нужна только после изменения файлов в `static/`).

## Запуск с сервером
### Что нужно
- Windows 10 или новее, любой современный браузер (Edge, Chrome).
- Python 3.9 или новее (https://www.python.org/downloads/, при установке отметьте «Add python.exe to PATH»).
- Интернет и дополнительные библиотеки не нужны: используется только стандартная библиотека Python.

### Запуск
1. Распакуйте архив в любую папку.
2. Дважды щёлкните `run.bat`. Откроется браузер со страницей http://127.0.0.1:8765/ .
3. Остановка: закройте окно консоли или нажмите Ctrl+C.

Если порт занят, запустите `python server.py --port 8766`.

Результат расчёта хранится на сервере (в браузерной версии хранятся параметры запуска, показатели пересчитываются при открытии страницы): после запуска на странице «Электровозы» его видно на «Анимации», «Показателях» и «Графиках». Если справочник изменён после расчёта, страницы предупреждают, что результат устарел. Клавиши на «Анимации»: пробел, стрелки влево и вправо, Enter.

## Роли
- **Пользователь** (без пароля): запуск расчёта, выбор горизонта, анимация, показатели, графики, схема, просмотр справочника и справки.
- **Администратор** (пароль): правка справочника параметров и справочника выработок и плеч, смена пароля, сброс значений, раздел импорта.
- При первом входе администратора программа просит задать пароль (не короче 12 символов). Пароль хранится только в виде хеша PBKDF2-SHA256 (600 000 итераций) в файле `data/admin.json`.
- После 5 неверных попыток вход блокируется на 15 минут, сеанс администратора истекает через 30 минут бездействия.
- Забытый пароль: закройте программу, удалите файл `data/admin.json`, запустите снова и задайте новый пароль. Это возможно только при доступе к файлам на компьютере.

## Данные
- `data/blocks.json`: выработки и плечи блоков (названия, длины, уклоны, скорости), правит администратор на странице «Общий расчёт»; без файла действуют значения по умолчанию.
- `data/reference.json`: изменённые администратором параметры (если файла нет, действуют значения по умолчанию).
- `data/admin.json`: хеш пароля администратора.
- `data/last_run.json`: последний расчёт (виден всем страницам; создаётся при запуске расчёта).
- Для резервной копии скопируйте папку `data`.

## Что умеет версия 0.1.2
Один маршрут «посты погрузки С-14 и С-15 → КДРВ №2», цепочка блок-участков с разминовками, электровозы Ferrit с составами из 9 ВДР, ПДМ ST1030 №2 как общий ресурс погрузки, окна работы по ТО и КТГ, горизонт смена или сутки, детерминированный режим. Груз в камерах не ограничен, путевая схема условная. Подробности и формулы: `docs/simulation_model_concept.md` и страница «Справка».

**Ограничение:** при трёх и более постах и двух и более ПДМ составы могут заблокировать друг друга на однопутной цепочке (диспетчер версии 0.1 не предотвращает тупики). Приложение показывает красное предупреждение, такой результат использовать нельзя. При параметрах по умолчанию блокировок нет.

- Для интерфейсных проверок нужны пакет `playwright` и Chromium (путь к браузеру можно задать переменной `CHROMIUM`).

## Структура
- `server.py`: локальный сервер, маршруты API, защита администратора.
- `sim/`: ядро имитации на Python (`engine.py`), кинематика (`kinematics.py`), параметры по умолчанию (`params.py`), номер версии (`__init__.py`).
- `static/`: страницы (`*.html`), `css/style.css`, `js/common.js` (общий каркас), `js/draw.js` (схема и графики), `js/p-*.js` (скрипты страниц).
- `static/js/engine.js`: то же ядро на JavaScript; `static/js/local-api.js`: хранилище браузера, пароль (WebCrypto PBKDF2), маршруты `/api/...` внутри страницы; `static/js/params-data.js`: создаётся из `sim/params.py` командой `python tools/gen_params_js.py`.
- `tools/`: `gen_params_js.py` (справочник для JavaScript), `build_web.py` (сборка `web/`).
- `web/`: готовая браузерная версия (создаётся `tools/build_web.py`).
- `tests/`: тесты.

Правило: любое изменение логики ядра вносится в `sim/engine.py` и `static/js/engine.js` одновременно; `tests/test_parity.py` ловит расхождение.
