# Логистика гор. −480 (шахта «Болашак»)

Приложение для расчёта логистических цепочек в подземных горных выработках: электровозы на гор. −480, самосвалы и ПДМ на гор. −402 и АТУ.

Адрес приложения (GitHub Pages): https://drjonibul-sys.github.io/Logistic-Bolashak/

| Папка | Что внутри |
|---|---|
| `docs/` | готовая сборка для GitHub Pages (её открывают на iPhone и iPad и ставят на экран «Домой») |
| `source/` | исходники приложения, тесты, инструменты сборки |
| `materials/` | документы проекта, чертежи, выгрузки DXF, таблицы Excel |
| `change_log.md` | журнал изменений и список ошибок, которые нельзя повторять |

## Как выложить новую версию
1. В `source/` внести правки, поднять `VERSION` в `source/sim/__init__.py`, добавить раздел «Что нового» в `source/README.md`.
2. Запустить `python source/tools/publish.py`: сборка запишется в `docs/`.
3. Закоммитить и отправить в ветку `main`. Через минуту-две GitHub Pages обновит сайт.
4. В приложении: Настройки → Обновления → «Проверить обновление». Адрес репозитория уже стоит источником по умолчанию.

## Включение GitHub Pages (один раз)
Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/docs`.
